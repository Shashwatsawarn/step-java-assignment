# Java Lab Programs

Solutions for STEP Semester 3 practice and assignment sheets.

## Folders
- `Week-01/Practice` and `Week-01/Assignment`
- `Week-02/Practice` and `Week-02/Assignment`
- `Week-04/Practice` and `Week-04/Assignment`
- `Week-05/Practice` and `Week-05/Assignment`

Each `.java` file is a self-contained runnable program with sample input in `main`.

## Run a program

```bash
cd Week-01/Practice
javac W1P1RockPaperScissors.java
java W1P1RockPaperScissors
```

Compile and run the file from its own folder because no Java packages are used.
